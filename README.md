# Synergy Hackathon Project Manager

Synergy is a **web-based project management portal** designed specifically for hackathon teams.  
It combines collaboration, analytics, and gamification to make hackathon participation smoother, more engaging, and more professional.

---

## 🚀 Features
- 📂 Team collaboration workspace  
- 📊 Analytics dashboard for tracking progress  
- 🎮 Gamification elements to boost engagement  
- 🌐 Multi-language support with `i18n.config.json`  
- ✅ Code quality ensured via ESLint  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js (planned)  
- **Deployment:** GitHub Pages / Vercel / Netlify  
- **Version Control:** Git & GitHub
